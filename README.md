# Portfolio
A striking Neo-Brutalist bento-style portfolio featuring high-contrast design, interactive elements, and a dynamic patch-notes system. Built with Vanilla JS and pure CSS.


# 🍱 Bento Portfolio - v0.1 BETA

Bu proje, **Neo-Brutalism** tasarım dilini temel alarak oluşturduğum, kişisel serüvenimi ve teknoloji yığınımı (tech stack) sergileyen interaktif bir Bento Grid portfolyosudur.

> **Durum:** 🚧 Şu an yoğun geliştirme aşamasında!

---

## 🎨 Tasarım Felsefesi
Sıradan, yumuşak hatlı ve pastel renkli sitelerden sıkıldığım için; **yüksek kontrast**, **sert kenarlar**, **belirgin gölgeler** ve **canlı sarı tonları** kullandım. Amacım hem göze çarpan hem de "ham" bir geliştirici ruhu yansıtan bir dijital ev oluşturmak.
